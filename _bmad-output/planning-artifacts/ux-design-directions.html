Order Entry Screen

Key decisions in this screen

  • Search bar always at top — primary path
  • Category chips below search — secondary path
  • Per-waiter Quick Items pinned above categories
  • Routing preview on the Send button (Kitchen/Bar split)
  • Quantity stepper appears inline when item added
  • Bar-fixed Send Order — always reachable, never hidden

Character

Spatial, visual, map-driven. Feels like Uber — tap a location, not a list.

Navigation

Visual floor plan → tap zone → table grid. Spatial mental model.

Best for

Staff familiar with the physical layout. Situational awareness at a glance.

Trade-off

More taps to reach a table. Map layout needs updating if restaurant changes.

Evaluation Guide — What to Look For

Direction A — Coastal Light

✓ Familiar app pattern — zero learning curve for Nina
✓ Onboarding-friendly for new staff
✓ Works well in mixed lighting


✗ Cards need outdoor variant to survive direct sunlight
✗ Chip + grid = 2 interaction steps to reach table

Direction B — Zone Map First

✓ Spatially intuitive — Nina "points" at her zone
✓ Whole-restaurant status at a glance
✓ Matches Uber/PickMe mental model


✗ One extra tap to reach a table vs Direction A
✗ Map layout needs configuring per restaurant
✗ Falls back to Direction A for non-map tenants

Direction C — Dark Operational

✓ All tables visible without scrolling
✓ Excellent for evening service
✓ Dense — experienced staff love it


✗ Washes out in direct beach sunlight
✗ Higher learning curve for new staff
✗ Less friendly for dispute screen (customer faces it)

Hybrid Option

Mix elements across directions. Common hybrid:

A as default + Zone Map as configurable toggle (B) + Dense view as a secondary "all tables" screen (C)

This is how Petpooja works — list view default, floor plan optional.
